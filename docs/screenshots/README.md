# Screenshots

These images are used by both the GitHub Pages site (`docs/index.html`) and the
repository `README.md`. The files currently checked in are **placeholders**
generated by `gen_placeholders.py` (stdlib-only Python). A real screenshot
generator should overwrite them **in place, keeping the exact filenames**.

Recommended size: 1600 x 1000 px (16:10), PNG. `hero.png` is also the
Open Graph / Twitter card image (`https://overkazaf.github.io/rift/screenshots/hero.png`),
so keep its important content inside the central 1200 x 630 area.

| File | What it should show |
|------|---------------------|
| `hero.png` | Rift window, rift-neon theme: a few command blocks, one failed block with the inline fix bar, AI chat sidebar docked right |
| `blocks.png` | Command blocks: exit-code gutter, duration/exit chips, hover toolbar (copy / ask AI / rerun / fold), one folded block |
| `ai-chat.png` | Docked AI chat sidebar streaming an answer next to terminal panes |
| `cmdk.png` | Cmd+K "ask about this" popover anchored to a selected block |
| `fix-suggestion.png` | Failed command (e.g. `cargo build`) with the inline fix suggestion bar ("Tab to accept") |
| `nl-command.png` | `# find the 10 largest files` at the prompt, turned into a generated command |
| `splits.png` | Several recursive split panes with tabs, one pane focused |
| `palette.png` | Command palette (Cmd+P) with fuzzy matches and Recent section |
| `browser.png` | Built-in browser panel docked beside the terminal, toolbar + address bar visible |
| `preview-accept.png` | Preview-Then-Accept modal for a dangerous command (e.g. `rm -rf build/`) with impact list |
| `effects-crt.png` | CRT effect enabled (scanlines, curvature, glow) |
| `hud.png` | HUD status strip (CPU / MEM / disk / git / uptime) |

Regenerate placeholders:

```bash
python3 docs/screenshots/gen_placeholders.py
```
